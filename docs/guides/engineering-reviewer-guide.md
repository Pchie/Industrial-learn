# Engineering Reviewer Guide

1. Accept the staging invitation and establish your own verified sign-in credentials.
2. Sign in at <https://industrial-learn-git-development-kolobe.vercel.app/auth/sign-in?next=%2Freview>.
3. Confirm that **Engineering Reviewer** appears in Profile and open the Reviewer workspace.
4. In **Awaiting review**, open **Basic Fluid Pressure**, item `LES-FLUID-PRESSURE-001`,
   content version `0.4.0`.
5. Review both source records, their relevant sections, reliability, and access status.
6. Check `EQ-FLUID-PRESSURE-001`, symbols, SI units, known-answer case, assumptions, model
   limitations, and implementation evidence.
7. Use **Preview as Student** to operate force and area controls, inspect the pressure
   response and live equation, run the challenge, and check mobile and keyboard behaviour.
8. Review each assessment question, expected answer, explanation, unit/tolerance rule, and
   competency mapping. This evidence is reviewer-only.
9. Complete the accessibility checklist for keyboard, labels, contrast, reduced motion,
   mobile layout, and numeric alternatives.
10. Select Approve, Request changes, or Reject; add substantive notes; confirm the exact
    version attestation; and submit.

Approve only if you are qualified, independent from the accountable author, and satisfied
with every required check. The decision does not publish the lesson.
