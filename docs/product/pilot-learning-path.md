# Fluid Engineering Pilot Learning Path

Date: 2026-09-04

## Purpose

`/learn/pilot` provides a narrow controlled-pilot route while the Fluid Mechanics
Foundations parent module remains unpublished. It does not change or bypass module
governance.

## Student Sequence

```text
Sign in
  -> Student Workspace
  -> Fluid Engineering Pilot
  -> Basic Fluid Pressure 0.4.0
  -> visual interaction and observations
  -> 200 kPa educational challenge
  -> Basic Fluid Pressure Check v2
  -> server-scored result and review
  -> saved dashboard evidence
```

The lesson applies `EQ-FLUID-PRESSURE-001` using the source-supported relationship from
`SRC-OPENSTAX-COLLEGE-PHYSICS-2012` and
`SRC-PSU-CIMBALA-PRESSURE-BASICS`.

## Visibility Rules

- The path resolves its lesson through the existing public lesson registry.
- If the exact approved lesson is unavailable, no draft substitute is displayed.
- Assessment availability is checked only for an authenticated student.
- The assessment link is shown only when the exact version passes the server publication
  gate.
- A mismatch produces an explicit closed-gate message, not a fallback assessment.
- The unpublished module is not added to public navigation or presented as approved.

Future lessons may join this collection only after their own public publication gates
pass. The collection is not a general curriculum publication mechanism.

## Ownership And Access

Lesson content remains public only under existing reviewed publication rules. Assessment
attempts, progress, scores, and competency evidence require an authenticated student and
remain private to that profile. Reviewer access does not imply access to student progress.
