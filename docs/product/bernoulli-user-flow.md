# Bernoulli Flow Lab User Flow

## Primary Flow

1. **See:** The lesson opens on a paused horizontal pipe contraction with P1, P2,
   direction, diameter, velocity, pressure, and a concise ideal-model warning.
2. **Change:** The student changes flow rate or section 2 diameter using a slider
   or its synchronised numeric input.
3. **Observe:** The visual, text state summary, measurements, and selected gauge
   update from the same simulation state.
4. **Connect:** Quick mode explains the relationship briefly. Engineering mode
   reveals `LiveEquation`, SI substitutions, symbols, assumptions, and steps.
5. **Challenge:** The student reaches the velocity target and predicts the P2
   relationship before revealing it.
6. **Apply:** A Venturi-style visual connects the ideal relationship to a practical
   measurement concept while naming the extra real-world requirements.
7. **Check:** Five non-graded questions test concept, pressure reasoning, units,
   head terms, and model limitations.
8. **Deep Dive:** Optional detail covers energy-head form, assumptions, and why
   real losses are outside the pilot.

## Desktop Priority

The main viewport, primary controls, pressure selection, gauge, and readings share
the visual stage. Observation, equation, challenge, application, and optional
detail follow as full-width lesson bands without nested decorative cards.

## Mobile Priority

The order is pipe visual, controls, measurements, observation, equation,
challenge, and application. Equations wrap inside the engineering view, the SVG
retains a stable aspect ratio, and number inputs remain available beside sliders.

## Keyboard And Assistive Technology

- Every slider has a labelled numeric alternative.
- P1, P2, and pipe sections are selectable with keyboard controls.
- Representation switching uses the shared accessible segmented control.
- Gauge value, velocity, pressure, head, and overall state are available as text.
- Challenge feedback is announced through a polite live region.
- Meaning is conveyed through labels, values, shape, and text, not colour alone.
- Reduced-motion mode removes continuous dot animation and preserves static arrows.

## Honest State Rules

The flow cue begins paused. Starting it changes presentation only and does not
advance physical time, award competency, or create a persisted completion. The
lesson displays `Engineering review required` and never presents the ideal result
as a safe pipe-system design.
