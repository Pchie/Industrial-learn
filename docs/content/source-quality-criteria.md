# Source Quality Criteria

## Reliability Levels

| Level | Source Type                                                                          | Use                                                   |
| ----- | ------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| 1     | Legislation, official safety guidance, IEC, ISO, SANS or official standards metadata | Governing safety, regulatory and standards references |
| 2     | Official manufacturer technical documentation                                        | Equipment-specific operating and safety information   |
| 3     | University or peer-reviewed educational material, open educational textbooks         | Core teaching definitions and equations               |
| 4     | Reputable engineering textbooks legally provided to the project                      | Core technical references when licensing is clear     |
| 5     | Existing internal content requiring verification                                     | Draft planning only                                   |

## Approval Criteria

An approved source must have:

- Stable source ID.
- Actual file or permitted metadata reference.
- Confirmed title and author or organisation.
- Confirmed edition, version or publication date when available.
- Copyright status.
- Relevant chapter, section or page metadata where cited.
- Named reviewer and review date.
- Evidence status set to `approved`.

Placeholder source records must never be approved.
