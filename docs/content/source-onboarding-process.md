# Source Onboarding Process

## Purpose

Industrial Learn source onboarding prevents unverified engineering claims from entering student-facing content.

Source IDs: IL-AGENTS-001, IL-CONTENT-GOV-001.

## Steps

1. Inspect `sources/` for actual files before editing content.
2. Confirm title, author or organisation, edition or version, publication date, access date, document type, copyright status and file integrity.
3. Assign or reuse a stable `SRC-*` ID.
4. Record relevant chapters, sections and pages only when they are visible in the actual source metadata.
5. Convert reviewed sections into focused knowledge files.
6. Keep every content, equation and simulation record at `Source required` until review evidence exists.
7. Submit content to the review workflow without self-approval.

## Missing Source Rule

When the source file is absent, record a source-needed item and do not invent citation details, page ranges, clauses, ratings or source approval.

## Copyright Rule

Do not store full copyrighted standards or textbook chapters unless the project has a lawful licence and storage approval. Knowledge files must use original explanations, short compliant quotations only where essential, and precise references.
