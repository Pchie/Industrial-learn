# Premium Frontend Principles

## Purpose

Industrial Learn should feel like a calm engineering workspace. Visual hierarchy must
help students find a useful next action, not exaggerate the size or readiness of the
curriculum. The homepage now uses actual publication-filtered lessons and connected
school links instead of the obsolete application-foundation placeholder.

## Shared Rules

1. Navigation remains Home, Learn, Simulations, Projects, Workspace and Profile where
   authenticated. Role destinations still come from the server account-access endpoint.
2. The theme control does not replace or bypass workspace selection. Private routes keep
   server-side role/capability checks regardless of which links are displayed.
3. Use quiet full-width sections, consistent reading widths, rem text and semantic
   controls. Do not surround the teaching visual with nested decorative panels.
4. A simulation presents the visual before its controls in document order; measurements
   and live equations follow. Desktop places controls/context beside the main viewport.
5. Preserve structured observations, challenges, explanations and Deep Dive content.
   UI polish is not permission to remove learning steps, hint restrictions or scoring.
6. Preview and unavailable states must stay honest. The hydraulic and Bernoulli inspection
   workspaces are protected previews, not new student-approved catalogue entries.
7. Optional 3D must not be downloaded for a catalogue card or default lesson view.
   Every 3D-dependent interaction needs a useful non-WebGL alternative.
8. Every interaction must work with keyboard controls and retain a clear exit. Meaning
   must not depend on colour, animation, hover, or pointer gestures alone.

## Change Boundaries

Global tokens/layout refine learning catalogue, lessons, dashboard and staff workspaces.
Existing loading, empty, failure and access-denied views inherit those tokens; no real
student data is substituted with sample analytics. Basic Fluid Pressure remains backed
by the same approved content, engineering functions and server-controlled assessment.
No source content, equation, migration, authentication flow or production setting is
changed by this work.

Human visual review and the open Prompt 49 operational/security gates still apply before
broader student testing. Frontend completion does not override a pilot NO-GO verdict.
