Run `npm ci` from the existing lockfile; offline reproduction needs a populated matching npm cache. Online registry install is normal for a new developer but was not the install exercised here.
5. Run typecheck, lint, format, content, migration and unit commands above in a clean shell with `RUN_STAGING_DB_INTEGRATION=false` and no live environment files/credentials. Do not run migration or fixture scripts.
6. For a local production-mode build, set only `APP_BASE_URL=http://127.0.0.1:3100`, `NEXT_PUBLIC_APP_ENV=test`, `INDUSTRIAL_LEARN_AUTH_MODE=local`, `INDUSTRIAL_LEARN_E2E=true`, `NEXT_TELEMETRY_DISABLED=1`, `PLAYWRIGHT_REUSE_SERVER=false`. The repository config builds and launches a fresh loopback server. Local signup creates only in-memory fixture identities, not live accounts.
